# Candidate-level numerical-safeguard audit

This directory contains the complete candidate-level audit used in the
Reviewer 1 rebuttal.

## Scope

The audit covers 6,000 candidate-bandwidth evaluations under the nominal
local-volume restriction \(Mh^d \ge 81\).

The complete records are in:

- `priority1_floor81_main_20260711_180209/all_candidate_bandwidth_rows.csv`

The corresponding per-testbed aggregate diagnostics are in:

- `priority1_floor81_main_20260711_180209/candidate_denominator_summary.csv`

The audit is generated by:

- `scripts/rebuttal/priority1_audit_full_floor81.py`

## Aggregate results

Across all 6,000 candidate-bandwidth evaluations:

- minimum estimated conditioning density:
  \(\min \widehat f_h = 0.1224813867920232\);
- minimum estimated denominator:
  \(\min \widehat D_h = 0.0008197018121466\);
- density-floor activations: 0;
- denominator-floor candidate activations: 0;
- denominator grid-point floor activations: 0.

The numerical safeguards were set at \(10^{-12}\), so neither safeguard
affected the candidate estimators or the selected bandwidths.
